# Dynamic Claude Code Generation

Replace the hardcoded `npm run demo` tradeeasy-demo script with a real Claude Code CLI session driven by the actual PRD and backlog artifacts produced by the product hub pipeline.

## Current state

`runDemoScript()` in `app/backend/src/demo/demo-runner.ts` spawns `npm run demo:reset && npm run demo` in `DEMO_PROJECT_PATH`. The demo script copies `templates/Messaging.tsx` into `src/pages/`, patches `App.tsx` and `Sidebar.tsx` at comment markers, commits, and runs Playwright. The feature written is always the same hardcoded template regardless of what the AI pipeline produced.

## Goal

Close the full loop: the docs generated by the product hub pipeline (PRD, backlog with acceptance criteria) drive the code Claude Code writes. Every Full Demo run produces a genuinely different implementation.

---

## Implementation

### 1. Load workflow artifacts — `demo-runner.ts`

Add `loadWorkflowArtifacts(workflowId: string)`:

```typescript
interface DemoArtifacts {
  goal: string;
  featureSlug: string;   // e.g. "in-app-messaging"
  prdExcerpt: string;    // problem statement + key user journeys (~1500 chars)
  backlogSummary: string; // first 3 stories with title, goal, benefit, first 2 AC each
}
```

- Query `SELECT item_id, goal FROM workflows WHERE id = ?`
- `loadLatestArtifactForStage(itemId, 'pm_prd')` from `../agents/artifact-helpers`
- `loadLatestArtifactForStage(itemId, 'pm_backlog')` — parse JSON, extract first 3 stories
- Derive `featureSlug` from first line of goal: lowercase, spaces→hyphens, max 30 chars
- Falls back to `runDemoScript()` if no PRD or backlog artifact found

### 2. Build the Claude Code prompt — `demo-runner.ts`

Add `buildDynamicPrompt(artifacts: DemoArtifacts): string`:


### 3. `runDynamicDemoScript(workflowId)` — `demo-runner.ts`

```typescript
export async function runDynamicDemoScript(workflowId: string): Promise<void>
```

Steps inside the function:
1. Call `loadWorkflowArtifacts(workflowId)` — fall back to `runDemoScript()` if nothing found
2. Reset: `git checkout main && git branch -D feature/<slug> 2>/dev/null; git checkout -- src/`
3. Branch: `git checkout -b feature/<slug>`
4. Build prompt from artifacts
5. Spawn Claude Code:
   ```
   claude --print
     --allowedTools "Read,Write,Edit,Glob,Grep,Bash"
     --max-turns 20
     --no-color
   ```
   CWD = `DEMO_PROJECT_PATH`, prompt via stdin
6. Stream output line-by-line into `RunState` (same map as `runDemoScript` — frontend polls existing `/run/status`)
7. On Claude exit: run `npx playwright test --reporter=list` in same CWD
8. Capture Playwright output as additional lines; set final `status` to `passed`/`failed`

### 4. New backend route — `demo-project-routes.ts`

```
POST /api/workflow/:id/demo-project/run-dynamic
```

Fire-and-forget call to `runDynamicDemoScript(id)`. Returns `{ ok: true }`.
Frontend polls the existing `GET /api/workflow/:id/demo-project/run/status` — no new endpoint needed.

### 5. Frontend — `DemoProjectSection.tsx`

Add a `⚡ Dynamic run` button alongside the existing `▶ Run demo` button. Show when:
- `run.configured` is true (`DEMO_PROJECT_PATH` set)
- A `workflowComplete` prop is `true` (passed from `PipelineTerminalView`)

```tsx
{run.configured && workflowComplete && !isRunning && (
  <button onClick={triggerDynamic} className="...">
    ⚡ Dynamic run
  </button>
)}
```

Add `triggerDynamicDemoRun(workflowId)` to `api.ts`:

```typescript
async triggerDynamicDemoRun(workflowId: string): Promise<{ ok: boolean }> {
  const response = await axios.post(
    `${this.baseURL}/api/workflow/${workflowId}/demo-project/run-dynamic`
  );
  return response.data;
}
```

Pass `isComplete={activeWorkflow?.status === 'complete'}` to `<DemoProjectSection>` in `PipelineTerminalView.tsx`.

### 6. Full Demo auto-trigger — `demo-webhook-routes.ts`

Replace `runDemoScript` with `runDynamicDemoScript` in the post-pipeline completion hook so the **Full Demo** button triggers real Claude Code generation end-to-end:

```typescript
// Before
runDemoScript(workflow.id).catch(...)

// After
runDynamicDemoScript(workflow.id).catch(...)
```

## Prerequisites

- `claude` CLI must be installed and authenticated on the server running the product hub backend
- `DEMO_PROJECT_PATH` env var must point to the tradeeasy-demo repo
- The tradeeasy-demo repo must have the comment markers in place:
  - `/* ── AI FEATURE IMPORTS` in `src/App.tsx`
  - `{/* ── AI FEATURE ROUTES` in `src/App.tsx`
  - `NAV_ITEMS` array in `src/components/Sidebar.tsx`
