# Product Strategy

> `strategy.md` is gitignored — your strategy stays local. This example uses a fictional company.

## North star

Every mid-market manufacturer runs their supply chain operations without manual data entry.

## Current period: Q1–Q2 2026

### OKRs

**O1 — Grow ARR to $5M by end of Q2**
- KR1: Sign 12 new logos (currently 68 customers)
- KR2: Expand 15 existing customers to additional connector seats
- KR3: Reduce time-to-live for new customers from 14 days → 7 days

**O2 — Establish Insights as a standalone growth driver**
- KR1: 20 customers activate Insights dashboard (currently 4)
- KR2: NPS for Insights reaches 35+ (currently 22)
- KR3: 3 expansion deals sourced from Insights upsell path

### Roadmap themes this period

1. **Connector depth** — add 30 new connectors in the SAP ecosystem (highest-demand segment)
2. **Onboarding speed** — rebuild the guided setup wizard to halve time-to-live
3. **Insights GA** — exit beta, add alerting/anomaly detection, launch pricing

## Explicit non-priorities (Q1–Q2)

- Enterprise (1000+ employee) deals — sales cycle too long for this period
- Custom connector SDK for developers — our ICP doesn't want to write code
- Mobile app — no demand signal from current customers

## Constraints

- Engineering headcount is frozen until Q3; no new hires
- Must maintain 99.9% uptime SLA — no big infrastructure migrations this half
- GDPR compliance review in March — no new data storage categories until review complete
